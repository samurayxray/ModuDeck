# ModuDeck — 3D print exports

Five supplied STL models converted to OBJ and 3MF. Units assumed millimeters (STL has no embedded units). All five STL meshes are watertight and have positive volume. Mechanical fit, print orientation, tolerances, and print-bed compatibility are **not verified**. 01-assieme and 03-interno-con-PCB are assembly/reference models, not necessarily single-piece prints. 02-esploso was not supplied as STL.
