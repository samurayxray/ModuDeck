# ModuDeck. 3D print exports

Five STL models provided were converted to OBJ and 3MF. The units are assumed to be millimeters (STL files do not have embedded units). All five STL meshes are watertight and have volume. Mechanical fit, print orientation, tolerances and print-bed compatibility are not verified. 01-Assieme and 03-interno-con-PCB are assembly models or reference models, not single-piece prints. 02-Esploso was not provided as an STL file.<img width="770" height="510" alt="module-monitor-pcb-3d-oblique-screenshot" src="https://github.com/user-attachments/assets/f8d2f657-c751-4a4a-8705-4d059e89fdac" />
