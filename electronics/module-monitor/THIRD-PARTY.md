# Library attribution

The local standard footprints, cached schematic symbols and STEP models come from the installed KiCad 10.0.7 library distribution, compiled by the KiCad community. Original attribution data remains in the copied files. Footprints were copied into project-local libraries and their model paths were changed to `${KIPRJMOD}/models` for portability. `ModuleMonitor:RaspberryPi_Pico_Common_Socketed` is a new carrier footprint using verified Pico geometry and the two original KiCad Pico assembly STEP models; it represents two female sockets rather than a soldered module.

KiCad library data is distributed under CC BY-SA 4.0 with the KiCad electronic-design exception. The full upstream license is retained in [models/KICAD-LICENSE.md](models/KICAD-LICENSE.md). See [KiCad 3D libraries](https://gitlab.com/kicad/libraries/kicad-packages3D), [footprints](https://gitlab.com/kicad/libraries/kicad-footprints) and [symbols](https://gitlab.com/kicad/libraries/kicad-symbols). The Pico geometry and pinout source is the [official Raspberry Pi Pico datasheet](https://datasheets.raspberrypi.com/pico/pico-datasheet.pdf). Generic LED and resistor STEP colors do not encode the actual resistor values or a manufacturer's detailed part model.
